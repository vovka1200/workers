# workers

Пул воркеров (бригада) для Go на дженериках: заданное число горутин берёт задачи из общего канала, выполняет одну функцию и отдаёт результаты в общий канал.

## Установка

```bash
go get github.com/vovka1200/workers
```

Требуется Go 1.22 или новее.

## API

```go
func NewBrigade[T any, R any](n int, do func(int, T) R) *Brigade[T, R]
```

Создаёт бригаду из `n` воркеров. Каждую задачу типа `T` воркер передаёт в `do` вместе со своим номером (от `0` до `n-1`), а результат типа `R` отправляет в `Results`.

| Член          | Назначение                                                                |
|---------------|---------------------------------------------------------------------------|
| `Start()`     | запускает `n` горутин-воркеров                                            |
| `Tasks`       | канал задач (`chan any`, без буфера), в него отправляются значения типа `T` |
| `Results`     | канал результатов (`chan any`, без буфера), из него читаются значения типа `R` |
| `Close()`     | останавливает воркеров и закрывает `Tasks`, `Results` и `Done`            |
| `Done`        | служебный канал остановки, используется в `Close()`                       |

## Пример

```go
package main

import (
	"fmt"

	"github.com/vovka1200/workers"
)

func main() {
	// Бригада из двух воркеров, каждый возводит число в квадрат
	brigade := workers.NewBrigade[int, int](2, func(id int, n int) int {
		return n * n
	})
	brigade.Start()

	// Tasks небуферизованный: отправка ждёт свободного воркера,
	// поэтому задачи отправляются из отдельной горутины
	go func() {
		for i := 1; i <= 5; i++ {
			brigade.Tasks <- i
		}
	}()

	sum := 0
	for i := 0; i < 5; i++ {
		sum += (<-brigade.Results).(int)
	}
	fmt.Println(sum) // 55

	brigade.Close()
}
```

## Фоновая очередь с одним воркером

Если отправитель не должен ждать, пока задача выполнится (например, HTTP-хендлер), поставьте перед бригадой буферизованный канал. С одним воркером задачи выполняются строго по порядку.

```go
brigade := workers.NewBrigade[string, error](1, func(id int, s string) error {
	return save(s)
})
brigade.Start()

// Результаты нужно читать всегда, иначе воркер заблокируется
done := make(chan struct{})
go func() {
	defer close(done)
	for r := range brigade.Results {
		if err, ok := r.(error); ok {
			log.Println(err)
		}
	}
}()

// Буфер перед бригадой: отправитель не ждёт воркера
queue := make(chan string, 100)
go func() {
	for s := range queue {
		brigade.Tasks <- s
	}
	// В Tasks больше никто не пишет, можно закрывать
	brigade.Close()
}()

queue <- "a"
queue <- "b"

// Остановка: закрыть буфер и дождаться, пока всё выполнится
close(queue)
<-done
```

## Особенности

- **`Tasks` и `Results` без буфера.** Отправка в `Tasks` ждёт, пока освободится воркер. Воркер, в свою очередь, ждёт, пока кто-нибудь прочитает его результат из `Results`.
- **`Results` нужно читать всегда**, даже если результат не нужен. Иначе воркер блокируется на отправке результата и больше не берёт задач, а `Close()` зависает.
- **При `n > 1` порядок результатов не гарантирован.** Результаты приходят в порядке завершения задач. Строгий порядок выполнения даёт только `n = 1`.
- **`Close()` дожидается текущих задач.** Воркер получает сигнал остановки, только когда возвращается к ожиданию задачи, поэтому начатая задача доводится до конца (при условии, что `Results` читается).
- **После `Close()` в `Tasks` писать нельзя.** Отправка в закрытый канал вызывает панику, в том числе если отправка ждала свободного воркера в момент вызова `Close()`. Прекратите отправку задач до вызова `Close()`.
- **Повторный вызов `Close()` безопасен** и ничего не делает. `Close()` вызывает владелец бригады (тот, кто вызвал `NewBrigade`); вызывать его одновременно из нескольких горутин нельзя.
- **`Close()` без `Start()` зависает**: сигнал остановки некому принять.
- **Тип задачи проверяется только во время выполнения.** `Tasks` имеет тип `chan any`, поэтому значение не того типа скомпилируется, но вызовет панику в воркере при приведении к `T`.
- **Результат читается как `any`** и приводится к `R` вручную: `(<-brigade.Results).(R)`.
